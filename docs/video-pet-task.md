# MOMO006 · 原视频动作接入

Owner mac16/root；用户明确授权替换默认兔子动作，目标是与其提供15秒视频动作、速度及片内流畅度一致。范围：本机macOS开发包，首页/登录/宠物屋/桌面共用播放器；保留原pet窗口、拖动、菜单、双击展开、收起、观察、建议、工具与账号。非目标：生成新角色/动作，模型外发视频，扩观察权限，改用户业务数据。

## 定位与方案

权威来源 output/rabbit-animation/rabbit-actions-15s.mp4：832×768、H264、24fps、视频362帧/15.083333秒、无alpha，带浅绿背景与圆圈。此前PhotoPetScene只有坐姿局部变形，不能还原睡眠/跳跃/转身，B1首个权威偏差为动作来源。新链：源视频→本机Vision逐帧前景蒙版→保留全帧全时间的透明VP9→AnimatedPet原生video→工作台及独立桌面窗口。禁止额外随机移动、镜像、变形或hover重启。源首尾姿态不相同，循环边界必须独立核验，不能声称原片天然无缝。

页面：P1登录/首页/侧栏/制作/宠物屋→C1 AnimatedPet；P2桌面→C2 pet.jsx→C1。S1源检查→S2本机去背景→S3本地资产持久保存→S4媒体原速解码/生命周期→S5最终页面动作与桌面交互→S6验收。S1/S3/S4/S5均程序；S2 macOS内置前景分割模型，不访问云端、不调用大模型。既有HTML允许file本地media，无须扩网络白名单。

产品视角：保留源全部动作、无裁耳/脚、透明背景、静音原速、减少动态可停、失败明确重试。不能以原静态兔悄悄兜底后宣称视频已生效。
技术视角：复用原组件/窗口/权限与SQLite，无schema更改。标准video播放，不逐帧JS重画或人工限帧，隐藏/出视口暂停后从原位置恢复，click不重置。错误释放媒体资源，customimage仍静态；controller默认参考视频模式停额外平移/转向，clamp与原窗口状态机继续生效。容量关注多实例视频解码与透明VP9支持；实际Chromium alpha与掉帧须验证。

并行边界：video_asset owns prepare scripts/public video assets；video_player owns共享组件/CSS/lifecycle tests；video_review owns controller及tests；root owns集成、文档、最终打包及原生验收。没有递归委派。
