# Momo 小作坊

用自然语言制作、运行和保存本机小工具的 Electron 桌面应用。保留精致的工作台与独立桌边宠物，不引入 Code OSS。

## 直接使用

本机 Apple Silicon 开发包：`release/mac-arm64/Momo 小作坊.app`。压缩包：`release/Momo 小作坊-0.7.11-arm64-mac.zip`。

使用约定的统一邮箱账号登录工作台，不提供本机注册。每次退出应用后需要重新登录；左下角账户可退出。当前是应用内固定账号校验，尚未连接云端账户服务器，不提供云同步或密码找回。既有工具会保留。

登录后可使用三个内置工具：

- CSV 差异核对：选择两份 UTF-8 CSV，按唯一键核对增删和字段变化，导出结果；目前不支持 XLSX，输入上限每份 4 MB。
- 文件命名：选择文件 → 检查实际预览 → 原生确认 → 执行；在工具内或任务记录中恢复名称，重开应用后仍可恢复。文件内容或目标位置变化时停止，不覆盖已有文件。
- 报价计算：录入成本、数量和毛利率，实时计算并导出 CSV。

自然语言制作：左下角个人空间 → 制作引擎设置，填写 OpenAI 兼容服务的接口地址（一般含 `/v1`）、模型名称和密钥，然后首页描述需求 → 制作 → 试运行 → 保存。修改需求会保留旧版本。工具箱可查看和恢复版本。

制作时，需求和当前工具代码会发送到自选模型服务；日常运行不会自动上传选择的本机文件。密钥使用 Electron safeStorage 加密保存，可在设置中移除。模型服务与费用由用户自行配置。

自定义工具在无 Node、无同源权限、禁止网络的 iframe 中运行。需要本机能力时，先由工具声明，再由用户授权该版本；读取文件还需用户主动选择。更换版本需重新授权。

宠物小屋支持命名、配色、导入图片、显示开关和安静模式。桌边宠物是独立透明窗口，可拖动顶部把手，从菜单打开工作台或最近工具。生成新形象需额外填写图像模型，服务需支持 `images/generations` 和 base64 图片输出；不会把预设换色伪装成图像生成。

## 今日陪伴（macOS 第一版）

左侧“今日陪伴”集中管理待办、提醒、记忆与工具优化。

- 待办可以自然语言设时间（如“明天下午3点”“10分钟后”），也可选择准确时间、修改、完成和稍后。应用需运行且已登录；锁屏/休眠期间不打扰，恢复后检查到期事项。系统通知还受macOS通知设置影响，宠物内保留提醒入口。
- 休息按实际活跃时间累计，工作/休息间隔可设置；空闲、锁屏、休眠不计入。观察暂停不影响明确约定的提醒。
- “记忆与观察”中默认关闭所有观察。可分别开启工具使用记录、指定文件夹单层变更次数、前台应用名称；不录屏、不读取输入、不读取文件内容。可排除应用、暂停1小时、移除目录或清除历史。记忆可以修改和忘记。
- “让制作引擎参考已确认记忆”默认关闭；开启后最多五条明确记忆随需求发送自选模型，原始观察记录不自动上传。
- “让工具更顺手”开启自主优化后，相同参数成功使用三次可自动记住报价输入或文件名前缀。核对规则和自定义工具变化先保留候选，查看差异、试用并确认才启用。每次优化可一键回退上一个版本，所有历史仍保留；回退工具不撤销已经执行的文件操作。
- 自定义优化使用真实OpenCode与用户配置的模型；无模型时会明确提示，内置工具与日常管家不依赖模型。自由生成代码的业务结果须人工检查。

## 开发与构建

要求本机 Node.js 24，npm，以及 Apple Command Line Tools（构建仅读应用名的Swift组件）；Electron 44.9.1 和 OpenCode 1.19.3 已锁定到 package-lock。

```sh
npm ci
# 如 npm 的脚本策略跳过 Electron 下载，显式执行官方安装器
node node_modules/electron/install.js
npm test
npm run desktop
npm run pack
npm run dist
```

`npm run dev -- --port 5186 --strictPort` 只提供网页预览。网页不具有桌面能力，不能完成真实自然语言制作。正式桌面从 `dist/` 本地文件启动，不依赖 Vite。

`npm run pack` 生成当前平台应用目录；`npm run dist` 生成 macOS arm64 ZIP。当前包为本机开发构建，尚未完成开发者签名、公证、自动升级及 Windows 实机验收，不作为商店发行包。

## 架构与文件

- `src/main.jsx`：工作台、工具制作和内置工具。
- `src/CustomTool.jsx` / `runtime-document.js`：自定义工具隔离运行、版本、设置和任务记录。
- `src/pet.jsx`：独立宠物窗口。
- `electron/main.cjs`：桌面生命周期、可信 IPC、授权和任务编排。
- `electron/opencode.cjs`：真实 OpenCode CLI、独立配置、结构校验、取消和超时。V1 仅让 Agent 返回工具代码，不给 Agent Bash、读写或安装权限。
- `electron/capabilities.cjs`：本机文件选择、读取、导出、改名/恢复、剪贴板、通知和打开宿主生成的文件。
- `electron/auth.cjs`：统一账号的 scrypt 哈希校验和进程内会话；不读写本机账户文件，失败冷却防连续尝试。
- `electron/store.cjs`：SQLite 工具、不可变版本、任务和操作账本。
- `electron/preload.cjs`：白名单 IPC，不暴露 Node 或原始文件路径。

窗口隐藏传统标题栏，保留macOS原生红黄绿按钮；顶部空白区域可以拖动。宠物播放用户原兔子与完整翻身动作，透明VP9原速24fps，默认momo-actions-refined.webm，共495帧约20.625秒。以清晰原2作首尾及poster，保留原2..362和翻身20..124的完整实际动作。转场用单源细节与独立底色校正，取消双图细纹平均及两张多余坐稳混合帧；翻身段围巾仅校正底色，纹理对比与alpha保持。尾段只对共同下巴白毛加局部底色，出口只让虹膜内部真实反光小岛连续移动和改变强度，眼形不动。没有输出模糊、强锐化或新增角色轮廓运动场，亚码级源毛纹差异仍保留，详见docs/validation-momo0710.md。自定义图片保持静态；视频失败显示同源清晰poster并可重试。旧资产保留可回退。单击桌面兔子打开菜单，双击展开工作台；收起/展开仍复用原窗口过渡。


桌面兔子可按住本体四向拖动，松手保存位置；安静模式使用原闭眼趴睡姿态、48%透明度，唤醒后继续原动作。菜单「收起宠物」在显示器可用区域底边保留细条，靠近探出，离开300ms后退回；探出后可选择「留在桌面」。停靠与工作台收起相互独立。详见docs/pet-interactions-task.md。

完整处理链见 `docs/architecture.md`，验收与限制见 `evidence/desktop-verification.md`，OpenCode 接口细节见 `docs/opencode-integration.md`。

## 数据与恢复

常规数据位于 `~/Library/Application Support/Momo 小作坊/`，首次运行初始化三个内置工具。测试使用单独的 `evidence/desktop-test-profile`，不会混入正常个人空间。可用 `MOMO_USER_DATA` 指定隔离数据目录。不再创建 `auth/account.json`；统一账号哈希随应用配置，会话和失败冷却只在进程内存中。

归档工具保留版本；在「我的工具 → 已归档」恢复。活动工具可从版本记录恢复旧版本。已改名的原始文件需先在任务记录恢复。退出后备份完整应用数据目录，可恢复工具、任务、加密设置和改名账本；不要仅复制正在写入的 SQLite 主文件。

原型回退备份：`evidence/prototype-backup-20261021-011139.tar.gz`。恢复源码前先另存当前目录；回退不自动撤销已经确认的文件改名。
