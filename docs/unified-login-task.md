# 统一账号替换本机账户

任务MOMO-003。用户明确撤回本机账户方案，要求指定统一邮箱与口令，删除应用本机账户。凭据原文不写文档或前端。

范围：统一固定账号的主进程校验、移除注册IPC和UI、停止本机账户文件读写、旧账户文件从活动目录移除、打包与真实登录验证。既有工具、版本、模型设置、任务与文件不删除。尚无账号服务器，不把固定账号登录描述成云端身份或云同步。

当前链：账户文件→创建/登录→主进程会话→工具/能力IPC。
目标链：应用内固定账号哈希→统一邮箱登录→主进程会话→既有工具/能力IPC。没有注册、称呼、确认密码或setupRequired创建流程；启动始终显示登录。登录成功、错误、退出、重启及未授权路径必须回读。

产品审视：按用户指定账号直接进入原工作台，去除被撤回的本机账户概念；保留精致外观与宠物。技术审视：复用现有会话、scrypt和可信IPC，内置盐和哈希不在前端存明文密码；本机账户文件即使存在或损坏也不能改变统一身份。登录仍无云端账号服务器，未来需另行接入。

分工：root主进程/前端入口/迁移/打包与验收；china_market固定账户KDF及测试；runtime_ui统一登录表单；table_engine只读账号路径审计。

旧活动账户只有隔离验收profile中的auth/account.json；正常个人空间未发现账户文件。停应用后将该文件移入独立回滚目录，活动账户目录不再保留；不触碰SQLite。

验收：正确指定账号与口令可登录；邮箱或密码错误拒绝；六位指定口令不被旧8位校验拦截；不能注册；退出及重启重新登录；旧本机账号无效；工具目录不变；原生窗口与宠物回归。回滚：保留0.2.0开发ZIP；旧账户文件可恢复隔离，恢复需人类明确选择，不能自动恢复本机身份。

结果：0.3.0打包完成，62/62测试通过；正常空间实际登录、退出、重启与再次登录通过。旧活动账户文件已隔离，工具保留。证据见evidence/unified-login-verification.md。
