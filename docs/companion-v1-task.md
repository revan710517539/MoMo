# MOMO004 · macOS 工作教练第一版

人类决策者：用户；当前所有者：root/mac16。授权范围：现有本地应用开发、隔离测试、打包与正常空间无损兼容；不发布、不写远端、不接触用户业务文件内容。

## 完整目标及最小交付

桌面连续宠物、收起展开、可编辑记忆与可控观察、证据触发建议、优化候选/自动低风险适配/一键回退、今日待办与休息提醒，均提供实际持久化和错误路径。macOS arm64先行，不引入Code OSS。模型依赖由用户配置；无模型配置明确报错，内置工具与日常管家不依赖模型。

当前链：用户手动描述→OpenCode生成→保存版本→受控工具运行；宠物固定导航。
目标链：登录→用户启用观察/记忆→最小本地事件→重复任务规则→建议→用户试用工具→成功使用记录→优化候选→结构/语法/权限验证→低风险默认值自动适配或人工试用确认→新版本→可回到前版。待办和休息由确定性调度执行；动画与窗口不依赖模型。

## 产品审视

服务非程序员女性工作者的表格、资料及交付流程，界面使用自然语言；美观、流畅、少打扰、知道发生了什么和可撤回为验收标准。观察默认关闭，可暂停、移除目录、删除记忆。只收集目录元数据、获准应用名和应用内工具事件，不录屏、不监听输入、不无限制控制其他应用。预测以建议展示，不自主决定用户目标。

## 技术审视与责任索引

- root：main/preload、Companion UI、现有工具使用钩子、native helper编译、集成与打包验收。
- china_market：electron/companion.cjs、可选Swift观察源和companion测试；settings.companion持久化。
- table_engine：electron/optimizer.cjs与测试；复用SQLite不可变工具版本，settings.optimizer保存候选与回退关系。
- runtime_ui：连续3D宠物、pet renderer、electron/pet-controller.cjs及测试；独立窗口与主窗口过渡。
- 所有权：现有store是持久事实；main是认证、任务、窗口和本机权限权威；OpenCode只规划与生成；工具运行继续使用sandbox与精确版本授权。

新增IPC仍校验主窗口/宠物与登录。子iframe无新权限。观察与优化在退出/锁屏/休眠时停止或暂停；任务晚到结果不可覆写、跨版本权限不继承；记录限量，不保存口令。前台应用通过本机Swift helper读取，不使用UI脚本。新依赖仅three（锁定版本），无远端资产。

## 验收与失败路径

单元/契约：关闭观察不采集；遗忘与目录移除生效；待办持久化/提醒去重/稍后/完成；idle休眠不算连续工作；旧版本保留/并发冲突/权限变化/一键回退；主进程认证拒绝。真实打包应用：登录→观察开关/记忆增删→待办提醒→工具三次使用建议→优化切换与回退→退出重开回读→收起仍有宠物/双击恢复。视觉验证连续运动不是图片翻页，多屏约束/减少动态和菜单焦点有测试。

无模型时生成候选显示配置错误；不伪造云模型成功。目录权限拒绝/消失显示状态且可移除。版本回退不等于撤销已改文件，文件撤销继续用原操作账本。流程中不允许生成工具调用新增观察API。
